Entry for [Robot Romance: One-Line Pickup Lines for AI](https://make.fun/c/u-markk-st-robot-romance-one-line-pickup-lines-for-ai-c23b8dfa) on make.fun — one joke pickup line, under 200 characters, aimed at a robot or an AI.

## The entry

> Are you a transformer? Because you turned all twelve heads of my attention straight to you — and not one of them is looking away.

## How it works

`main.ts` (Node 22, stdlib only) validates the line against the gate — 1 to 200 characters, a single line, not only white space — then writes exactly that line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), with no trailing newline. The run is fully deterministic: the same line every time.
